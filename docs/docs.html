ruid Documentation

ruid (@theruid/ruid) is an autonomous, model-agnostic terminal coding agent designed for cross-platform software engineering.

Zero Vendor Lock-in: ruid treats all LLMs through a dynamic capability abstraction — natively connecting to Anthropic Claude 3.7/Sonnet 5, OpenAI o1/o3-mini/GPT-4o, Google Gemini 2.0/3.7, DeepSeek R1/V3, Groq, OpenRouter, local Ollama, LM Studio, or custom proxy routers (like 9router) without modifying workflow or tool code.
⚡ Capability Abstraction
Model-aware detection for reasoning budgets, structured outputs, prompt caching, and tool execution.
🧠 Thinking & Reasoning
Live streaming thought elapsed counters, collapsed thought badges, and dynamic /think toggle.
🛡️ Safety Risk Tiers (0–4)
Firewall defending sensitive credentials (.env, keys) and offering [CODE], [PLAN], and [AUTO] modes.
🚀 Subagent Swarms & Git Worktrees
Parallel fleet delegation (explore, coder, reviewer) executing in isolated git worktrees.

1. Installation & CLI Usage

Install globally via npm or run directly using npx across macOS, Linux, and Windows:

Terminal 
# Global installation
npm install -g @theruid/ruid

# Launch interactive coding agent
ruid

# Run interactive provider setup wizard
ruid setup

# View CLI options
ruid --help

Global Configuration Directory

ruid stores its global configuration, conversation histories, and audit trails under ~/.ruid/ (or %USERPROFILE%\.ruid on Windows). Custom directories can be set via the RUID_CONFIG_DIR environment variable.

2. Setup Wizard & Configuration Engine

Run ruid setup in your terminal to enter the interactive setup wizard. The wizard performs real-time validation:

  • Validates API key format and accessibility for selected providers.
  • Tests round-trip endpoint latency and displays status badges.
  • Queries the remote /v1/models endpoint and auto-populates available models.
  • Saves configuration directly to ~/.ruid/config.json.

Configuration Format (~/.ruid/config.json)

~/.ruid/config.json 
{
  "providers": {
    "anthropic": {
      "type": "anthropic",
      "apiKeyEnv": "ANTHROPIC_API_KEY",
      "defaultModel": "claude-sonnet-5"
    },
    "openai": {
      "type": "openai",
      "baseUrl": "https://api.openai.com/v1",
      "apiKeyEnv": "OPENAI_API_KEY",
      "defaultModel": "gpt-4o"
    },
    "deepseek": {
      "type": "openai",
      "baseUrl": "https://api.deepseek.com",
      "apiKeyEnv": "DEEPSEEK_API_KEY",
      "defaultModel": "deepseek-reasoner"
    },
    "9router": {
      "type": "openai",
      "baseUrl": "http://localhost:20128/v1",
      "apiKey": "sk-your-key",
      "defaultModel": "ag/gemini-3.7-flash-high"
    },
    "ollama": {
      "type": "openai",
      "baseUrl": "http://localhost:11434/v1",
      "defaultModel": "llama3.2"
    }
  },
  "default": {
    "provider": "9router",
    "model": "ag/gemini-3.7-flash-high"
  },
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}

3. Capability-Based Provider Abstraction

Modern LLMs are not uniform text generation APIs. Rather than locking to an OpenAI-only shape or treating reasoning models as standard chat bots, ruid dynamically discovers ModelCapabilities:

Capability Flag Anthropic (Claude 3.7 / Sonnet 5) OpenAI Reasoning (o1 / o3-mini) DeepSeek (R1) Gemini Thinking (2.0 / 3.7) Local / Ollama (Llama 3.2)
supportsTools true true false (text focus) true true
supportsThinking true true true true false
supportsStructuredOutput true (synthetic tool) true (json_schema) false (prompt fallback) true false (prompt fallback)
supportsPromptCaching true (ephemeral headers) true (auto-cache read) true false false
contextWindow 200,000 200,000 64,000 1,000,000 32,768 – 128,000
maxOutputTokens 64,000 100,000 8,192 64,000 4,096

4. Thinking & Reasoning Streams

ruid parses reasoning deltas across different wire formats in real time (Anthropic thinking_delta, DeepSeek reasoning_content, OpenAI reasoning, and Gemini thought):

  • Live Streaming: Renders a live elapsed counter: ● thinking… (2.4s).
  • Post-Generation Badge: Collapses into a minimal summary: ● thought for 2.4s.
  • Dynamic /think Toggle: Type /think to toggle thinking on or off on the fly. When disabled, ruid passes thinking: { type: "disabled" } / reasoning_effort: "low" and silences thought tokens.

5. Router & Proxy Integration (9router, OpenRouter)

When routing through proxies like 9router or OpenRouter, model names often carry prefixes such as ag/gemini-3.7-flash-high or openrouter/anthropic/claude-3.7-sonnet. ruid strips router prefixes to detect underlying model capabilities and allows custom capability overrides in ~/.ruid/config.json:

Custom Capability Override Example 
"capabilities": {
  "supportsThinking": true,
  "supportsStructuredOutput": true,
  "contextWindow": 500000
}

6. Safety Risk Tiers & Operational Modes

ruid protects your machine with a 5-tier safety classification:

  • Tier 0 (Safe Read-Only): read_file, list_dir, glob, grep, git_status, git_diff, git_log, web_search. Always auto-approved.
  • Tier 1 (Workspace Mutations): write_file, edit_file. Displays visual diffs for review.
  • Tier 2 (Safe Non-Mutating Commands): ls, pwd, echo, git log, npm test.
  • Tier 3 (Mutating / Process Commands): rm, git push, background services, MCP server tools.
  • Tier 4 (Critical / Credentials Boundary): Any attempt to access .env, id_rsa, credentials.json, or run destructive commands like rm -rf /. Always prompts for confirmation.

Operational Modes

Press Tab or run /mode to cycle modes:

Mode Behavior
[CODE] Standard interactive mode. Prompts before writing files or running mutating shell commands.
[PLAN] Exploration only. File modifications and destructive commands are blocked; read-only research is allowed.
[AUTO] Autonomous execution. Auto-approves file writes and build scripts, while defending Tier 4 credential boundaries.

7. Context Compaction & Token Budgeting

To avoid context overflow during multi-turn sessions, ruid runs two-phase compaction:

  • Phase 1 (Micro-Compaction at 70% threshold): Truncates old tool outputs into concise single-line headers while preserving recent turns.
  • Phase 2 (Semantic Compaction at 85% threshold): Prompts the LLM to create a structured XML summary (<context_summary>) of past turns, discarding raw older history while preserving critical findings.

8. Subagent Swarms & Multi-Agent Fleets

For complex architectural changes or broad codebases, ruid spawns specialized subagents in parallel:

  • explore: Read-only research specialist for dependency tracing and definition discovery.
  • coder: Implementation specialist for precise file edits.
  • reviewer: Adversarial verification and test runner.

9. Git Worktree Isolation & Instant Rollbacks

Subagents can run in isolated git worktrees created under .git/worktrees/, preventing conflicting changes on your main branch. Once verified, changes merge back cleanly.

ruid also takes filesystem snapshots before every tool execution. If a generated change causes regressions, revert immediately with:

/rollback

10. Process Management & Interactive Prompt Detection

Background tasks and long-running services (like dev servers or watchers) run under a dedicated Process Manager:

  • Interactive Prompt Trap: Detects hanging interactive CLI prompts (e.g. [y/n], Password:, Select a framework:) and safely terminates them instead of freezing the agent loop.
  • Process Tree Cleanup: Uses taskkill /T /F on Windows and SIGKILL process-group trees on Unix to prevent orphaned zombie processes.

11. Built-in Tool Catalog

12. Model Context Protocol (MCP) Extensibility

Extend ruid with any custom MCP server by declaring it in ~/.ruid/config.json:

~/.ruid/config.json (MCP Configuration) 
"mcpServers": {
  "context7": {
    "command": "npx",
    "args": ["-y", "@upstash/context7-mcp"]
  },
  "database": {
    "command": "node",
    "args": ["./mcp-db-server.js"]
  }
}

Connected MCP tools are discovered at startup and can be listed at any time using /mcp.

13. Slash Commands & Keyboard Shortcuts

Command / Shortcut Function

/mode [code|plan|auto] Switch permission mode
/model [id] Open interactive model picker with capability badges
/providers Browse and switch configured LLM providers
/connect [name] Connect to a provider directly
/tasks Show active task plan checklist
/rollback [turn] Revert file modifications from a previous turn
/sessions Search and resume saved conversations
/mcp List connected MCP tools & servers
/clear Clear current conversation history
Tab Cycle operational mode
PageUp / PageDown Scroll message history viewport
Ctrl+C Interrupt active generation or double-press to exit

14. Session History, Search, & Migrations

Conversations are persisted as structured JSON in ~/.ruid/sessions/. Search across previous session titles and message contents with:

/sessions

Or resume a session directly by running /resume.

15. Audit Trail Logging (~/.ruid/audit.jsonl)

Every tool call, permission decision, and filesystem mutation is recorded as a structured JSON record in ~/.ruid/audit.jsonl for compliance and security observability.
