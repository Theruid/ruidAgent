ruid Documentation

ruid (@theruid/ruid) is an autonomous, model-agnostic terminal coding agent designed for cross-platform software engineering.

Zero Vendor Lock-in: ruid natively interfaces with Anthropic, OpenAI, DeepSeek, Google Gemini, Groq, OpenRouter, local Ollama, LM Studio, or any OpenAI-compatible proxy with dynamic capability detection.

Quick Installation

Install ruid globally via npm or run directly with npx:

# Global installation (recommended)
npm install -g @theruid/ruid

# Run interactive coding agent
ruid

# Run provider configuration wizard
ruid setup

Provider Setup Wizard

Run ruid setup to enter the interactive terminal wizard. The wizard tests network latency, validates API keys, fetches live models, and saves configuration directly to ~/.ruid/config.json.

Core Architecture

The agent is constructed from decoupled modular systems:

  • Capability-Based Provider Abstraction: Queries model support for tool calling, thinking/reasoning, structured output, prompt caching, and context limits before dispatching requests.
  • Autonomous Agent Loop: Manages token budgeting, two-phase history compaction, permission prompt interceptors, and tool executions.
  • Permission Engine (Risk Tiers 0–4): Defends system boundaries by isolating sensitive credential files (.env, id_rsa) and requiring user confirmation for destructive actions.
  • Ink-Powered Fullscreen TUI: Renders live response streaming, elapsed thought counters, tool result badges, interactive diffs, and task execution boards.

Provider Configuration (~/.ruid/config.json)

All provider endpoints and models are managed in ~/.ruid/config.json:

{
  "providers": {
    "anthropic": {
      "type": "anthropic",
      "apiKeyEnv": "ANTHROPIC_API_KEY",
      "defaultModel": "claude-sonnet-5"
    },
    "openai": {
      "type": "openai",
      "baseUrl": "https://api.openai.com/v1",
      "apiKeyEnv": "OPENAI_API_KEY",
      "defaultModel": "gpt-4o"
    },
    "9router": {
      "type": "openai",
      "baseUrl": "http://localhost:20128/v1",
      "apiKey": "sk-your-key",
      "defaultModel": "ag/gemini-3.7-flash-high"
    }
  },
  "default": {
    "provider": "9router",
    "model": "ag/gemini-3.7-flash-high"
  }
}

Capability-Based Abstraction

Rather than treating all models as basic text generators, ruid queries ModelCapabilities to tailor request payloads and parsing:

Capability Flag Anthropic (Claude 3.7 / Sonnet 5) OpenAI Reasoning (o1 / o3-mini) DeepSeek (R1) Gemini Thinking (2.0 / 3.7)
supportsTools true true false (text focus) true
supportsThinking true true true true
supportsStructuredOutput true (tool constraint) true (json_schema) false (prompt fallback) true
contextWindow 200,000 200,000 64,000 1,000,000

Thinking & Reasoning Streams

When reasoning models generate thought tokens (via Anthropic thinking_delta, DeepSeek reasoning_content, or OpenAI/Router reasoning):

  • Live Streaming: Displays an animated ● thinking… (3.2s) counter.
  • Post-Turn Summary: Collapses into a minimal ● thought for 3.2s badge.
  • Dynamic Toggle: Toggle reasoning dynamically during any turn using /think.

Modes & Safety Risk Tiers

Press Tab or use /mode to cycle operational modes:

  • [CODE] Mode: Default interactive mode. Asks before writing files or running mutating shell commands.
  • [PLAN] Mode: Architectural exploration. All mutation and destructive tools are blocked; read-only research is auto-approved.
  • [AUTO] Mode: Autonomous execution. Auto-approves safe and file mutation tools, but isolates sensitive Tier 4 credentials.

Commands & Keybindings

Command / Key Function
/think Toggle extended thinking/reasoning ON or OFF
/mode <code|plan|auto> Switch operational permission mode
/model [id] Open interactive model picker with capability badges
/providers Open configured provider selector
/tasks Display active task execution checklist
/rollback [turn] Revert all filesystem changes made in a specific turn
/sessions Search and resume previous conversation sessions
Tab Cycle permission mode
PageUp / PageDown Scroll message history up and down
Ctrl+C Interrupt streaming turn or double-press to exit

Model Context Protocol (MCP)

Integrate custom external tools and data sources by declaring MCP servers in ~/.ruid/config.json:

"mcpServers": {
  "context7": {
    "command": "npx",
    "args": ["-y", "@upstash/context7-mcp"]
  }
}

View connected MCP tools in the session by running /mcp.
