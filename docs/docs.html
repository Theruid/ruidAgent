Overview of ruid

ruid (@theruid/ruid) is an autonomous, model-agnostic terminal coding agent designed for cross-platform software engineering.

Full Provider Freedom: Connect directly to Anthropic Claude 3.7/Sonnet 5, OpenAI o1/o3-mini/GPT-4o, Google Gemini 2.0/3.7, DeepSeek R1/V3, Groq, OpenRouter, local Ollama, or any custom router endpoint like 9router without changing your workflow.

Quickstart

Install globally via npm and launch the agent in any project repository:

Terminal 
# 1. Install globally
npm install -g @theruid/ruid

# 2. Launch interactive coding agent
ruid

# 3. Or run the provider setup wizard
ruid setup

Setup Wizard

Run ruid setup to launch the interactive terminal setup wizard. It validates your API keys, tests round-trip network latency, fetches live model lists from endpoints, and writes persistent configuration to ~/.ruid/config.json.

Architecture & Workflow

ruid coordinates multi-step software development through decoupled modules:

  • Capability Resolver: Dynamically queries model capabilities (reasoning tokens, structured output, prompt caching, tool support, context windows) before constructing requests.
  • Autonomous Agent Loop: Executes multi-turn tool loops with two-phase history compaction (micro-compaction at 70% and semantic history compaction at 85%).
  • Permission Risk Firewall (Tiers 0–4): Defends system integrity by auto-approving safe inspections while requiring explicit approval for file writes and shell execution.
  • Ink Fullscreen TUI: Renders live response streaming, elapsed thought counters, tool result badges, interactive diffs, and task execution boards.

Provider Configuration (~/.ruid/config.json)

You can configure multiple providers and switch between them on the fly:

~/.ruid/config.json 
{
  "providers": {
    "anthropic": {
      "type": "anthropic",
      "apiKeyEnv": "ANTHROPIC_API_KEY",
      "defaultModel": "claude-sonnet-5"
    },
    "openai": {
      "type": "openai",
      "baseUrl": "https://api.openai.com/v1",
      "apiKeyEnv": "OPENAI_API_KEY",
      "defaultModel": "gpt-4o"
    },
    "9router": {
      "type": "openai",
      "baseUrl": "http://localhost:20128/v1",
      "apiKey": "sk-your-key",
      "defaultModel": "ag/gemini-3.7-flash-high"
    },
    "ollama": {
      "type": "openai",
      "baseUrl": "http://localhost:11434/v1",
      "defaultModel": "llama3.2"
    }
  },
  "default": {
    "provider": "9router",
    "model": "ag/gemini-3.7-flash-high"
  }
}

Capability-Based Abstraction

Different models have fundamentally different operational constraints. ruid queries ModelCapabilities to tailor request payloads and parsing:

Capability Anthropic (Claude 3.7 / Sonnet 5) OpenAI Reasoning (o1 / o3-mini) DeepSeek (R1) Gemini Thinking (2.0 / 3.7)
supportsTools true true false (text focus) true
supportsThinking true true true true
supportsStructuredOutput true (synthetic tool) true (json_schema) false (prompt fallback) true
contextWindow 200,000 200,000 64,000 1,000,000
maxOutputTokens 64,000 100,000 8,192 64,000

Thinking & Reasoning Streams

When reasoning models generate thought tokens (Anthropic thinking_delta, DeepSeek reasoning_content, OpenAI reasoning, or Gemini thought):

  • Live Streaming: Shows ● thinking… (2.4s) with a clean animated counter.
  • Completed Turn: Collapses into ● thought for 2.4s to keep chat history clean.
  • Dynamic Toggle: Run /think to toggle reasoning ON or OFF at any time. When disabled, ruid passes thinking: { type: "disabled" } and silences reasoning streams.

Router & Proxy Models (9router, OpenRouter)

When using custom router prefixes like ag/gemini-3.7-flash-high, openrouter/anthropic/claude-3.7-sonnet, or 9router/..., ruid automatically normalizes model identifiers to detect underlying model capabilities.

You can also define custom capability overrides in ~/.ruid/config.json:

"capabilities": {
  "supportsThinking": true,
  "supportsStructuredOutput": true,
  "contextWindow": 500000
}

Ollama & LM Studio

For local execution with Ollama or LM Studio, set the baseUrl in your configuration. Local hosts (localhost, 127.0.0.1) do not require an API key.

Permission Tiers & Operational Modes

ruid classifies every action into safety risk tiers:

  • Tier 0 (Safe Read-Only): read_file, list_dir, glob, grep, git_status, git_diff, git_log, web_search.
  • Tier 1 (Workspace File Writes): write_file, edit_file. Displays visual diffs for approval.
  • Tier 2 (Safe Non-Mutating Shell): ls, pwd, cat, echo, git log, npm test.
  • Tier 3 (Mutating / Process Shell): rm, git push, background services, MCP tools.
  • Tier 4 (Critical / Credentials Boundary): Access to .env, id_rsa, or dangerous shell commands (rm -rf /). Always requires explicit confirmation.

Press Tab or run /mode to cycle operational modes:

  • [CODE] Mode: Standard mode. Prompts before writing files or running mutating shell commands.
  • [PLAN] Mode: Research only. All file mutations and destructive commands are blocked.
  • [AUTO] Mode: Autonomous execution. Auto-approves file writes and build commands, while defending Tier 4 boundaries.

Subagent Swarms & Fleets

For complex architectural changes, ruid spawns specialized subagents in parallel:

  • explore: Read-only research specialist.
  • coder: Focused implementation specialist.
  • reviewer: Adversarial verification and test runner.

Git Worktree Isolation

Subagents can execute inside temporary, isolated git worktrees. Changes are verified and tested in isolation before being merged back to your working branch.

Snapshots & Rollback

ruid records filesystem snapshots before modifying files. If a generated change causes regressions, revert immediately with:

/rollback

Commands & Keyboard Shortcuts

Command / Shortcut Action
/think Toggle thinking/reasoning ON or OFF
/mode [code|plan|auto] Switch permission mode (or press Tab)
/model [id] Open interactive model picker with capability badges
/providers Browse and switch configured LLM providers
/connect [name] Connect to a provider directly
/tasks Show active task plan checklist
/rollback [turn] Revert file modifications from a previous turn
/sessions Search and resume saved conversations
/mcp List connected MCP tools & servers
/clear Clear current conversation history
Tab Cycle operational mode
PageUp / PageDown Scroll message history viewport
Ctrl+C Interrupt active generation or double-press to exit

Built-in Tool Catalog

ruid includes native tools for software development:

  • Filesystem: read_file, write_file, edit_file, list_dir, glob, grep.
  • Git Operations: git_status, git_diff, git_log.
  • Process Execution: bash, process_status, process_logs, process_kill with interactive CLI prompt detection.
  • Web Research: web_search (DuckDuckGo HTML) and web_fetch (HTML to clean Markdown).
  • Task Management: task_create, task_update, task_list.

Model Context Protocol (MCP)

Extend ruid with any Model Context Protocol (MCP) server by declaring it in ~/.ruid/config.json:

"mcpServers": {
  "context7": {
    "command": "npx",
    "args": ["-y", "@upstash/context7-mcp"]
  }
}

Session History & Persistence

All conversations are saved to ~/.ruid/sessions/. Search full-text conversation history with /sessions or resume directly with /resume.
