Control & Autonomy Matrix

Three Specialized Modes.
Complete Developer Control.

Cycle effortlessly between safe human-in-the-loop review, zero-mutation architectural planning, and high-velocity autonomous execution.

[CODE] MODE Default Safe

Human-in-the-Loop Safe Execution

Read-only tools (grep, glob, read_file) run automatically. Any file writes, shell commands, or destructive actions prompt for human confirmation (y/n/a).

  • Auto-approves read & search tools
  • Interactive diff preview on write
  • Instant git turn snapshots
Best for: Daily engineering & refactoring
[PLAN] MODE Architect

Read-Only Architecture & Planning

Zero mutations allowed. The agent traverses complex dependency graphs, reads documentation, decomposes epic user stories into atomic tasks, and generates comprehensive plans.

  • All file modification disabled
  • Interactive Task Tracking (/tasks)
  • Design spec & RFC generation
Best for: System design & code audits
[AUTO] MODE Autonomous

High-Velocity Autonomous Execution

Unrestricted agent iteration loop. Auto-executes multi-file creations, runs test suites, reads compiler errors, and self-corrects until all criteria are met.

  • Pre-approved execution loop
  • Automatic build & test healing
  • Tier-4 sensitive guards (.env safety)
Best for: Rapid prototypes & bug squashing

Open Standard Extensibility

Connect MCP Servers & Expand Agent Capabilities.

ruid natively implements Anthropic's Model Context Protocol. Give your agent superpowers: persistent multi-session memory, live web documentation lookup via Context7, database introspection, or proprietary APIs.

01
Persistent Memory Server
Retain architectural decisions, project conventions, and user preferences across coding sessions.

Live Documentation Search (Context7)

03
Zero Boilerplate Configuration
Defined simply in ~/.ruid/config.json under the standard mcpServers schema.
~/.ruid/config.json (MCP Configuration) 
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    },
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
