ruid Developer Guide & Documentation

ruid (@theruid/ruid) is an autonomous, model-agnostic CLI coding agent engineered for daily software engineering. It connects natively to Anthropic, OpenAI, DeepSeek, Groq, Ollama, OpenRouter, or custom OpenAI-compatible endpoints with zero telemetry lock-in.

⚡ Zero Telemetry & Private

Source code and keys never leave your machine unless communicating with your explicitly configured LLM provider.

🛡️ Granular Safety Matrix

5-tier risk boundaries defending .env and secret files, with instant git turn rollbacks via /rollback.

1. Installation & CLI Usage

Install globally via npm or execute on-demand across macOS, Linux, and Windows (PowerShell/CMD/WSL):

Terminal Installation

# Install globally from npm registry

$ npm install -g @theruid/ruid

# Launch the interactive terminal coding environment

$ ruid

# Launch provider configuration wizard

$ ruid setup

Global Config Directory: Configuration, memory files, and session histories are stored in ~/.ruid/ (or %USERPROFILE%\.ruid on Windows). Override with the RUID_CONFIG_DIR environment variable.

2. Setup Wizard & Configuration Schema

Run ruid setup or type /setup inside the CLI. The setup wizard tests endpoint round-trip latency, queries /v1/models, and saves credentials to ~/.ruid/config.json.

~/.ruid/config.json
{
  "providers": {
    "anthropic": {
      "type": "anthropic",
      "apiKeyEnv": "ANTHROPIC_API_KEY",
      "defaultModel": "claude-3-7-sonnet-20250219"
    },
    "openai": {
      "type": "openai",
      "baseUrl": "https://api.openai.com/v1",
      "apiKeyEnv": "OPENAI_API_KEY",
      "defaultModel": "gpt-4o"
    },
    "deepseek": {
      "type": "openai",
      "baseUrl": "https://api.deepseek.com",
      "apiKeyEnv": "DEEPSEEK_API_KEY",
      "defaultModel": "deepseek-chat"
    },
    "ollama": {
      "type": "openai",
      "baseUrl": "http://localhost:11434/v1",
      "defaultModel": "qwen2.5-coder:32b"
    }
  },
  "default": {
    "provider": "anthropic",
    "model": "claude-3-7-sonnet-20250219"
  }
}

4. Thinking & Reasoning Streams

ruid transparently normalizes reasoning deltas across different provider protocols:

  • ● Live Streaming: Displays real-time thought duration counters: ⠋ thinking… (1.8s).
  • ● Collapsed Summary: Once reasoning finishes, the header collapses neatly: ✔ thought for 1.8s.
  • ● Dynamic Toggle (/think): Toggle thinking on or off at any moment without restarting the session.

5. Operational Modes & Safety Risk Matrix

ruid enforces a strict 5-tier safety classification:

[CODE] Mode

Default safe mode. Read tools auto-execute. Mutating tools (write_file, edit_file, bash) prompt with visual diffs for approval.

[PLAN] Mode

Architect mode. Zero file mutations allowed. Explores codebases and decomposes goals into structured tasks (/tasks).

[AUTO] Mode

High-velocity autonomous loop. Pre-approves file writes and build iterations while strictly preserving Tier-4 credential boundaries.

6. Subagent Swarms & Git Worktree Isolation

For large refactors or security audits, ruid fans out specialized subagents running inside isolated Git worktrees:

⚡ subagent_parallel: 3 workers dispatched

• Worker 1 (EXPLORE): Maps dependency graph in src/security/

• Worker 2 (CODER): Edits auth middleware in isolated worktree

• Worker 3 (REVIEWER): Runs test suites and verifies regressions

✔ All worktrees merged and cleaned up automatically.

7. Model Context Protocol (MCP) Integration

Connect any MCP server simply by adding it to ~/.ruid/config.json under the mcpServers key: 

"mcpServers": {
  "context7": {
    "command": "npx",
    "args": ["-y", "@upstash/context7-mcp"]
  },
  "memory": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-memory"]
  }
}

Run /mcp in the terminal to inspect all discovered tools and connection statuses.

8. Custom Skills & Tool Execution Hooks

Create domain workflows in .ruid/skills/<skill-name>.md and trigger them with slash commands (e.g. /review, /audit).

Configure automated pre/post tool hooks (such as linters or formatters) in ~/.ruid/config.json: 

"hooks": {
  "postToolUse": [
    {
      "tool": "edit_file",
      "command": "npx prettier --write \"$FILE_PATH\""
    }
  ]
}

9. Auto-Memory & Session History

ruid persists architectural decisions, user feedback, and conventions across coding sessions in .ruid/memory/. Run /sessions or /resume to browse previous conversations with live fuzzy search.

10. Built-in Tool Catalog

Tool Name Description Risk Tier

write_file Writes or creates files, auto-creating directory tree Tier 1 (Mutating)

glob / grep Wildcard file discovery and bundled ripgrep content search Tier 0 (Safe)
bash Runs shell commands with timeout and interactive prompt trap Tier 2-3 (Command)
rollback Granular git turn rollback restoring pre-turn filesystem state Tier 0 (Safe)
